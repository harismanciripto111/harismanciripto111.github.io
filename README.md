# 0xRaiman — Portfolio

Persona-5-style portfolio with a Ragna Crimson theme: crimson palette, a looping fire/aura hero,
background music, and a contact form.

Live: https://harismanciripto111.github.io/ (or the repo's GitHub Pages URL)

## Edit your content
- Name, bio, role line: `index.html`
- Email and GitHub username: `js/model.js` (`contactEmail`, `githubUser`)
- Music: `assets/music/bgm.mp3`
- Hero image: `assets/hero/ragna.jpg`

## Run locally
```
python3 -m http.server 8000   # then open http://localhost:8000
```
